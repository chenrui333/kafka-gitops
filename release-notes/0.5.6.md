## Highlights

This patch maintenance release refreshes the Kafka client, runtime dependencies, test dependencies, and release automation. It includes no application code changes.

## Maintenance

- Update `org.apache.kafka:kafka-clients` from `4.3.1` to `4.4.0`.
- Update Jackson from `2.22.2` to `2.22.4`.
- Update SLF4J from `2.0.19` to `2.0.20`.
- Update Logback from `1.6.3` to `1.6.6`.
- Update Spock from `2.4-groovy-5.0` to `2.5-groovy-6.0` and JaCoCo from `0.8.15` to `0.8.16`.
- Gate release publication on the Kafka 3.9 and Kafka 4 compatibility test lanes, run against the exact tagged commit.
- Run Java CI on pull requests and `main` pushes instead of every push.
- Avoid execution-time project access in the Gradle version task.
- Refresh pinned GitHub Actions for artifact upload, Docker login, Docker build/push, and docs Python setup.
