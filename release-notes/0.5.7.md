## Highlights

This patch maintenance release refreshes dependencies, the release packaging plugin, test tooling, and CI automation. It includes no application code changes. The build still targets Java 21.

## Maintenance

- Update Jackson from `2.22.4` to `2.23.0`.
- Update the Gradle Shadow plugin from `8.3.11` to `9.6.1`. The executable jar no longer bundles `META-INF/versions/9/module-info.class`; the jar runs from the classpath, so behavior is unchanged.
- Update the Groovy test dependency from `4.0.33` to `6.0.0` and the JUnit Platform launcher from `1.14.4` to `6.1.3`.
- Run CI and release builds on JDK 25; the Gradle toolchain still compiles for Java 21.
- Update pinned GitHub Actions to new major versions: checkout v7, setup-java v6, setup-python v7, configure-pages v6, upload-pages-artifact v5, deploy-pages v5, and action-gh-release v3. Also update docker/login-action to v4.8.0.
- Raise the Renovate open-PR limit to 30.
